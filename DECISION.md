# Decision

**Reel 1 – One-person company with Grok bot agents (DfdYoFTva3u).** You set up role-based bots (inbox manager, researcher, writer, reviewer, chief of staff). Each one has a written charter: what it owns, what good work looks like, and when it has to stop and ask you. You teach a task once, save it as a routine, and it runs on a schedule (daily calendar brief) or on a trigger (a new lead asks about pricing). Several bots also work together in a "group chat" toward one objective. **Usefulness 8/10**: replying to pricing questions, morning briefs and lead outreach are weekly chores for any solo founder. **Buildability 8/10**: you only need an LLM API (xAI's Grok API is OpenAI-compatible), YAML files and a small scheduler, and it can ship with an offline demo mode. **Clarity 8/10**: the reel spells out the charter fields, the approval line, the trigger examples and the agent roles. Total: **24/30**.

**Reel 2 – Faceless Shorts pipeline with Claude + Higgsfield MCP + frame QA (DfauwQ0vq_Z).** You find outlier videos on vidIQ, a 3-agent Claude system writes hooks and scripts, Higgsfield turns them into Shorts, and a Claude Code agent checks one frame per second for warped hands and garbled text. **Usefulness 6/10**: helpful for a small niche of channel farmers. **Buildability 4/10**: vidIQ and Higgsfield are paid, and video generation can't be demoed offline. Only the frame-QA step stands on its own. **Clarity 4/10**: the reel says outright that the details are in a paid guide. Total: **14/30**.

**Reel 3 – Self-improving AI ad loop with ARCADS + Meta Ads (DeUHKoWzQ8T).** A spy agent ranks competitor hooks from the Meta Ad Library, a design agent makes 10 AI-actor ads, and an optimizer launches them, checks CPA after 3 days and scales the winners. **Usefulness 7/10** for advertisers. **Buildability 2/10**: it needs a paid ARCADS account, a Meta Ads account with ad spend, and Ad Library access that has to be approved. Spending real money automatically is also risky. **Clarity 6/10**. Total: **15/30**.

**Pick: Reel 1.** It's the only one a person can clone and run on a laptop today with a single API key (or none, in demo mode). The core ideas carry over directly to a small, testable program: charters with a hard approval gate, taught routines with schedule and keyword triggers, and a researcher → writer → reviewer handoff run by a chief of staff. The other two mostly wrap paid SaaS tools.
